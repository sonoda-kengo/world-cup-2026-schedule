# FIFA World Cup 2026 Schedule

A fast static Next.js schedule viewer for the 2026 World Cup.

## Features

- Static export for Vercel/CDN-friendly delivery
- Netherlands and Japan time display
- English and Japanese UI
- Team flags
- Search, stage, and group filters

## Project structure

```txt
.
├── schedule/
│   ├── fifa_world_cup_2026_schedule_nl.md
│   │                                   # Schedule source read at build time
│   └── fifa_world_cup_2026_schedule_nl.html
│                                       # Original HTML reference, not used by the app
├── src/
│   ├── app/
│   │   ├── globals.css                  # Global black/neon visual style
│   │   ├── layout.tsx                   # Root layout and metadata
│   │   └── page.tsx                     # Static home page
│   ├── components/
│   │   └── ScheduleView.tsx             # Search, filters, language/timezone toggles
│   ├── data/
│   │   ├── teamCodes.ts                 # Team name to country code mapping
│   │   └── types.ts                     # Schedule TypeScript types
│   └── lib/
│       ├── flags.ts                     # Country flag rendering
│       ├── i18n.ts                      # English/Japanese labels
│       ├── scheduleMarkdown.ts          # Markdown schedule parser
│       └── time.ts                      # Netherlands/Japan time formatting
├── next.config.ts                       # Static export config
├── package.json
└── README.md
```

`out/` is generated by `npm run build`. It contains the exported static HTML, JavaScript, CSS, and copied public assets. Do not edit it directly and do not commit it; rebuild it from source instead.

## Schedule source

The app reads `schedule/fifa_world_cup_2026_schedule_nl.md` at build time.

The Markdown table must keep these columns:

```md
| date | time | group | stage | home | away | label | venue |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Thu 12 Jun | 21:00 | A | group | Mexico | South Africa |  | Mexico City |
```

Valid `stage` values are `group`, `r32`, `r16`, `qf`, `sf`, `3p`, and `final`.
Dates and times are treated as CEST / Amsterdam time, UTC+2.
